# Contributing

Contributions are welcome.

1. Fork the repository and create a focused branch.
2. Keep ChromaPlex compiler/runtime changes separate from GUI/AI integration where possible.
3. Preserve upstream license notices for vendored code.
4. Run `python3 -m unittest discover -s tests -v` before opening a pull request.
5. Describe what changed, how it was tested, and any platform-specific limitations.

Please avoid committing API keys, generated secrets, build directories or personal configuration.
